# SIGEM Engenharia Clínica

Sistema de Gestão de Engenharia Clínica desenvolvido para controle de equipamentos hospitalares, rastreabilidade, estoque e apoio às atividades operacionais.

## Funcionalidades

- Dashboard Operacional
- Command Center
- Cadastro de Equipamentos
- Gestão de Equipe
- Controle de Estoque
- Histórico de Movimentações
- Site Plan do Projeto
