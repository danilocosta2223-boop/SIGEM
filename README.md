🏥 Portal de Engenharia Clínica Brasil
Sistema Web para gestão, monitoramento de equipamentos médico-hospitalares, documentação do projeto e controle de processos da Engenharia Clínica.

📌 Sobre o Projeto
O Portal de Engenharia Clínica é uma plataforma desenvolvida para centralizar e otimizar o fluxo de trabalho das equipes de Engenharia Clínica. O sistema permite o cadastramento, acompanhamento do histórico de manutenções e gerenciamento de inventário de equipamentos médicos em tempo real.

📁 Estrutura do Projeto
Engenharia-Clinica/
├── index.html                  # Página principal (Landing Page)

└── paginas/
    ├── dashboard.html          # Painel indicador com estatísticas e gráficos
    ├── command.html            # Centro de comando e controle
    ├── site-plan.html          # Planejamento do site e documentação técnica
    ├── equipe/                 # Informações da equipe de desenvolvimento e gestão
    └── cadastro-equipamentos/
        ├── index.html          # Visão geral do módulo de cadastro
        ├── cadastro.html       # Formulário de registro de novos equipamentos
        ├── equipamentos.html   # Listagem e consulta de equipamentos
        └── historico.html      # Histórico de manutenções e calibrações

💻 Como Executar o Projeto
Clonar o repositório
git clone https://github.com/danilocosta2223-boop/Engenharia-Clinica.git
Acessar a pasta
cd Engenharia-Clinica
Abrir o sistema
Abra o arquivo index.html em qualquer navegador ou utilize a extensão Live Server no VS Code.

🎯 Objetivo
O SIGEM foi desenvolvido para auxiliar as atividades de Engenharia Clínica, promovendo melhor controle dos equipamentos hospitalares, gestão de informações técnicas e apoio à tomada de decisões operacionais.
